# Johnathan Lo — GitHub Pages site

Static personal academic website for GitHub Pages.

## Pages

- `index.html` — non-scrollable splash/home page
- `cv.html` — full curriculum vitae
- `research.html` — research page
- `publications.html` — publications page
- `random.html` — miscellany page
- `404.html` — fallback page
- `styles.css` — shared styles
- `assets/johnathan-avatar.jpg` — cropped profile photo
- `assets/splash-landscape.jpg` — splash background
- `assets/favicon.svg` — fish favicon

Deploy by placing these files at the root of a GitHub Pages repository.
